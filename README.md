## 🚀 Quick Start

### Enable GitHub Pages

1. Go to your repository: `https://github.com/HenkVenter1987/Hitches-and-More`
2. Click **Settings** (top menu)
3. Click **Pages** (left sidebar)
4. Under "Build and deployment":
   - Select **Source**: `main` branch
   - Click **Save**
5. Wait 1-2 minutes for GitHub to build
6. Your site will be live at: `https://HenkVenter1987.github.io/Hitches-and-More/`

### View Locally

Simply open `index.html` in your web browser to preview.

## 🎨 Customization

### Update Your Information

Edit `index.html` footer section:
```html
<p>ABN: [Your ABN] | Email: info@versatilehitch.com.au | Phone: [Your Phone]</p>
```

### Change Pricing

Edit the pricing section in `index.html`:
```html
<span class="price">$1,850</span>
```

### Modify Colors

Edit the gradient colors in `styles.css`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```
